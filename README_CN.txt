Content Flow Demo Portfolio - Vercel Upload Guide

这个文件夹是给 Vercel / GitHub 使用的静态作品集模板。

你需要把英文成品 MP4 放入 videos 文件夹，并改成下面这些文件名：

1. videos/puma_ultra_match_fgag_en.mp4
2. videos/puma_fa_malaysia_jersey_en.mp4
3. videos/swxp_graphic_tee_en.mp4
4. videos/puma_quarter_socks_en.mp4
5. videos/puma_palomo_t7_shorts_en.mp4

注意：
- 这里建议放 English final export，不要放 MS / Malay 版本。
- 不要放 API Key、Token、.env、源码或后台截图。
- 如果视频太大，建议先用 ffmpeg 压缩成 720p 或 1080p web preview。
